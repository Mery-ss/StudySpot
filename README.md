# StudySpot

StudySpot er en mobilapplikation udviklet i React Native.

Appens formål er at hjælpe nye studerende med at finde gode steder at studere. Som ny studerende kender man ikke nødvendigvis de forskellige studiesteder i området eller ved, hvilket sted der passer bedst til ens behov.

StudySpot gør det nemmere at finde et passende studiested og sammenligne steder ud fra blandt andet støjniveau, Wi-Fi, strøm og hvilken type studiearbejde stedet er bedst egnet til.

## Funktioner

- Se en liste over forskellige StudySpots
- Vælg et StudySpot og se flere detaljer
- Se information om støjniveau, Wi-Fi, strøm og hvad stedet er bedst egnet til
- Naviger mellem appens forskellige screens

## Teknologi

Appen er udviklet med:
- React Native
- Expo
- React Navigation
