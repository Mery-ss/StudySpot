# StudySpot 📍

StudySpot er en mobilapplikation udviklet i React Native med Expo.

Appen er målrettet nye studerende på CBS og har til formål at gøre det nemmere at finde forskellige steder at studere på og omkring CBS.

## Funktioner

StudySpot giver brugeren mulighed for at:

- Se en liste over forskellige studiesteder
- Se information om støjniveau, Wi-Fi og strøm
- Se hvad de forskellige steder egner sig bedst til
- Filtrere mellem alle, stille steder og steder til gruppearbejde
- Gemme studiesteder som favoritter
- Se yderligere information om det enkelte studiested
- Navigere mellem appens forskellige screens

## Teknologi

Appen er udviklet med:

- React Native
- Expo
- React Navigation

## Brugerinddragelse

StudySpot er blevet afprøvet af to nye CBS-studerende for at få feedback på appens funktioner og muligheder for videreudvikling.
